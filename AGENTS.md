# GiftFinder для Windows, macOS и Linux

- Это portable-приложение поиска; не добавляйте покупки, сообщения или доступ к сессиям пользователя без отдельного запроса.
- Обычный профиль: `%LOCALAPPDATA%\GiftFinder\GiftFinder`. Сохраняйте настройки, избранное и поиски при обновлениях. Для проверок задавайте `GIFT_FINDER_DATA_DIR` в отдельной папке проекта и `QT_QPA_PLATFORM=offscreen`. Не запускайте обычный GUI без разрешения пользователя.
- `core.py` — данные и профиль; `catalogue.py` — полный локальный каталог и точные пары коллекция/модель; `providers.py` — поиск и автоматическая пагинация; `cache.py` — SQLite; `currency.py` — справочные курсы; `previews.py` — общие изображения; `selectors.py` — подвижные фильтры; `ui.py` — основной экран; `design.py` — тема и анимации; `views.py` — адресная перерисовка и плавная прокрутка.
- Группы в `themes_curated.json` — явные списки визуально проверенных моделей. Новая модель не включается в тему по ключевому слову. Отличайте Minecraft от общих пикселей и случайных совпадений названий.
- В версии 0.7.1 доступны 19 тематических подборок и монохромки. Девять новых групп содержат 110 проверенных пар; Пепе — 32 модели вне отдельно доступной коллекции Plush Pepe. Сохраняйте исключения: Pepelatz не Пепе, Android из Mini Oscar не Star Wars, Pokerface/Poker Chips не Pokémon. Новые названия поддерживаются исходниками переводов `translations/08-v7-themes.txt` и всеми JSON-пакетами локалей.
- В интерфейсе валюта называется GRAM. Старые ответы API и профили могут использовать TON; сохраняйте исходную точность сумм. Stars сравниваются по покупательскому ориентиру Fragment, с датой и пометкой приблизительности.
- Fragment и Portals читаются напрямую; остальные площадки — через browse.tg. Индекс, локальный кэш и прямые данные должны быть различимы. Только полный успешный обход прямого источника может удалять отсутствующие предложения из соответствующего поискового диапазона.
- Не сохраняйте cookies и временные параметры Fragment API. POST `searchAuctions` используется исключительно для чтения следующей страницы публичного поиска.
- Тесты: `python -m pytest tests -q --basetemp .test-work`. Дополнительные проверки и сборка описаны в README.md.
- Сборка: `python -m PyInstaller GiftFinder.spec --distpath dist --workpath build`. Сохраните исключение несовместимого ICU из PATH сборочной среды. Проверяйте EXE через `--smoke-test` с отдельной папкой, без видимого окна.
- Нативная упаковка для текущей ОС: `python tools/build_release.py` (на macOS этот скрипт также готовит ICNS/DMG). macOS/Linux нельзя кросс-компилировать из Windows. Матрица GitHub Actions проверяет Windows x64, macOS arm64/x64 и Linux x64/arm64. Готовые пакеты — в `release-dist/`; требования и мобильные ограничения — в `docs/PLATFORMS.md`.
- Путь профиля и ранних ошибок — `platform_support.data_directory()`: сохраняйте Windows-профиль и используйте Qt/XDG на остальных ОС. На macOS/Linux интерфейс наследует системный шрифт; в тестах не предполагайте русский язык системы.
- Android использует `mobile/main.py` и `giftfinder/mobile_ui.py`, общий поисковый движок и отдельную сенсорную компоновку. Инструкция сборки и подписи — `mobile/README.md`; CI — `.github/workflows/android-build.yml`. Не меняйте настольный вход и профиль ради APK. Ключ подписи хранится вне Git; не меняйте его при обновлениях и не выводите signing secrets. Для выпуска нужен обычный ARM64 APK, x86_64 с `GIFT_FINDER_ANDROID_SMOKE=1` предназначен только для CI.
- Проверяйте Android нативной установкой `adb install --no-incremental`, запуском, HTTPS-изображением, системной кнопкой Back, отрисованным поворотом и сохранением CSV через DocumentsUI. Геометрия кадра или живой процесс сами по себе не доказывают отрисовку. Не обходите Qt lifecycle произвольными задержками, повторами запуска или изменениями killProcess; сохраняйте закреплённые узкие исправления `mobile/android_hook.py`.
- Проверяйте архитектуру, Android-зависимости и настоящее ELF/RELRO-выравнивание всех библиотек, включая Python bundle; ZIP-выравнивание не заменяет ELF-проверку. Входы Android-сборки закреплены в `mobile/android-build-inputs.json`; смена версий, рецептов и флагов должна менять fingerprint совместимости кеша. Не исправляйте ELF одной заменой p_align в заголовке.
- Свежие цены индекса должны обновлять локальный кеш на экране; старый индекс не вытесняет более свежие данные, живой прямой ответ сохраняет приоритет. Отсутствие коллекции в старом справочнике Portals не является полным успешным обходом объявлений и не разрешает очистку кеша. Регрессии — `tests/test_audit_engine.py`.
- Упаковщик использует новый временный staging на каждый пакет. Не переносите в релиз содержимое прошлой папки package через overlay-копирование и не очищайте чужие или пользовательские папки ради сборки.

- Не возвращайте чтение файлов, декодирование PNG и масштабирование в paintEvent/delegate.paint. Для фоновых операций используйте QImage; QPixmap создавайте в потоке GUI. Сохраняйте кэш составных превью, адресную перерисовку и обновление модели без reset при изменении цен.
- `i18n.py` и `locales/` — встроенные переводы и CLDR; `controls.py` — поиск валют; `icons.py` — кэш флагов и значков. Первый запуск использует язык системы; ручной выбор хранится в прежнем профиле. Язык не меняет валюту, поиск или черновик фильтров. Проверки этих сценариев — `tests/test_v4.py`; внеэкранные экраны — `verify_release_ui.py`.
- Для измерений используйте benchmark_ui.py с отдельной папкой; не считайте offscreen-замеры доказательством плавности на любом мониторе. Проверяйте уменьшение движения и остановку анимаций после завершения.
