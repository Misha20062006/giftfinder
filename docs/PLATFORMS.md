# Платформы и сборка GiftFinder 0.7.1

Общая поисковая логика для Windows, macOS, Linux и Android. Настольные пакеты создаются каждый на своей ОС; Android использует отдельный мобильный интерфейс и официальный инструмент PySide6.

| Пакет | Требования | Как запустить |
|---|---|---|
| Windows x64, ZIP / EXE | Windows 10 или 11 x64 | Распаковать ZIP и запустить `GiftFinder.exe` |
| macOS arm64, DMG | macOS 14+, Apple Silicon (M1 и новее) | Открыть DMG, перенести `GiftFinder.app` в Applications |
| macOS x64, DMG | macOS 14+, Intel | Открыть DMG, перенести `GiftFinder.app` в Applications |
| Linux x64, tar.gz | glibc 2.35+, например Ubuntu 22.04+ | Распаковать архив и запустить `start-giftfinder.sh` |
| Linux arm64, tar.gz | glibc 2.39+, например Ubuntu 24.04+ | Распаковать архив и запустить `start-giftfinder.sh` |
| Android arm64-v8a, APK · preview | Android 9+ (API 28), 64-битная ARM-система | [Скачать APK](https://github.com/Misha20062006/giftfinder/releases/download/v0.7.1-android.1/GiftFinder-0.7.1-Android-arm64-v8a.apk), открыть и разрешить установку из выбранного источника |

Для готовых пакетов Python не нужен. Linux-сборки используют системные OpenGL/EGL/X11-библиотеки. На Debian/Ubuntu при их отсутствии:

```sh
sudo apt-get install libegl1 libopengl0 libxkbcommon-x11-0 libxcb-cursor0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 libxcb-xinerama0 libxcb-randr0 libxcb-shape0
```

Настольные сборки без коммерческой цифровой подписи и нотариального заверения Apple. ОС может запросить подтверждение доверия приложению. Android APK подписан постоянным ключом проекта; Google Play не используется. Системные требования Linux ARM64 и macOS обусловлены текущими бинарными пакетами Qt, а не только Python.

## Профиль и обновления

На Windows сохранён прежний путь `%LOCALAPPDATA%\GiftFinder\GiftFinder`. На macOS используется `~/Library/Application Support/GiftFinder/GiftFinder`, на Linux — `$XDG_DATA_HOME/GiftFinder/GiftFinder` или `~/.local/share/GiftFinder/GiftFinder`. Папки приложения и профиля разделены: замена программы не удаляет настройки, избранное и сохранённые поиски. Автоматический перенос профиля между устройствами не выполняется.

На Android профиль хранится во внутренней папке приложения. Установка новой версии APK поверх прежней с тем же ключом сохраняет профиль; удаление приложения удаляет его локальные данные.

## Сборка из исходников

Нужен Python 3.12, соответствующий архитектуре пакета. Из корня репозитория, в отдельном виртуальном окружении:

```sh
python -m pip install -r requirements-lock.txt
python tools/build_release.py
```

Скрипт создаёт пакет в `release-dist/`, запускает его вне экрана с отдельным профилем и записывает SHA-256. На macOS для DMG нужны стандартные `sips`, `iconutil` и `hdiutil`. Локальный запуск исходников: `python app.py`.

[GitHub Actions](../.github/workflows/desktop-build.yml) запускает тесты, нативную сборку и проверку упакованной программы на пяти системах. Внеэкранная проверка подтверждает запуск и основные функции интерфейса, но не заменяет ручную проверку на каждом компьютере, графическом драйвере или живой площадке.

## Android preview

Для телефона сделана отдельная адаптивная компоновка: каталог, крупные элементы управления, фильтры на отдельном экране, прокрутка касанием и системная кнопка Back. Сохранены общие источники поиска, фильтры, валюты, избранное и сохранённые поиски. CSV сохраняется через системный выбор файла без доступа ко всему хранилищу. APK запрашивает только обычные разрешения интернета и состояния сети.

В Android-плагин Qt 6.12.0 перенесено [официальное исправление QTBUG-146706](https://github.com/qt/qtbase/commit/59e4671814e9e25e316ed7ec1fe3e5d276141914): после закрытия всплывающего меню главный экран остаётся доступен Android accessibility. Плагин пересобирается из закреплённых исходников и SDK; логика поиска и жизненный цикл приложения для этого не меняются.

В CI собирается обычный подписанный ARM64 APK; архитектура и выравнивание всех библиотек проверяются и внутри Python bundle. Отдельная сборка x86_64 с офлайн-данными проверяется в Android 16 эмуляторе с 16-КБ страницами: нативная установка и запуск, HTTPS-загрузка закреплённого PNG из GitHub, SQLite, charset-normalizer, фильтры, Back для меню и списков, прокрутка языков, отрисовка после поворота и сохранение CSV через DocumentsUI с чтением результата. Версия образа и фактические параметры Android сохраняются в результатах проверки; минимум приложения остаётся Android 9+, целевой SDK — 35. HTTPS-проверка подтверждает транспорт, а не доступность api.changes.tg или площадок. Это не проверка обычного ARM64 APK на физическом телефоне; реальный поиск на всех площадках с Android также не проверен. Поэтому Android выпущен отдельно как **preview**, без замены стабильного настольного релиза.

Инструкции, закреплённые версии инструментов и подпись: [mobile/README.md](../mobile/README.md). [Qt поддерживает Widgets на Android](https://doc.qt.io/qt-6/android.html); [официальный инструмент PySide6](https://doc.qt.io/qtforpython-6/deployment/deployment-pyside6-android-deploy.html) собирает приложение на Linux или macOS. x86_64 smoke APK из артефактов CI предназначен для проверки интерфейса, а не для обычного поиска.

## iOS

Для iOS [официальный путь PySide6](https://doc.qt.io/qtforpython-6/deployment/deployment-pyside6-ios-deploy.html) требует macOS, полного Xcode и подписи для устройства; готовой iOS-сборки в релизе нет.
